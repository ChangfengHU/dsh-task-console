# Packaged Studio guide snapshots

`studio_read_guide({id:"execution"|"handoff"})` returns fixed complete text, SHA256 and scope. It reads no project path or parent checkout and makes no provider/host command call. The current Task/session/role fence still applies. It is a read-only skill-gate exception, not a successful `skill` load, execution evidence or quality receipt. `studio_status.guides` exposes only the two IDs, titles, hashes, scope and exact next calls; it does not inflate every status response with the full documents.

The reviewed sources are parent `autonomous-studio/STORYBOARD_EXECUTION.md` and `autonomous-studio/DSH_STUDIO_HANDOFF_COOKBOOK.md`. `src/studio-guides.ts` embeds their exact UTF-8 strings using JSON encoding plus SHA256. When updating either document, refresh its text and hash together, compare the decoded embedded UTF-8 bytes with that source, and run `test/studio-guides.test.ts`. Do not interpolate Markdown into shell/JS template literals: backticks and `${...}` are content. Production bundles need only the TS module; parent source documents are maintenance provenance, never runtime inputs. No automatic copy into a Task workspace is claimed. Relative documentation links in the snapshots are repository source references, not promises that those files exist in a Task workspace.

The new tool enters the existing `studio-runtime` capability list through `STUDIO_TOOL_NAMES` and `src/presets.ts`; there is no second registration mechanism. Existing saved compositions/capability locks may report missing-tool drift until refreshed through the existing author-spec-preserving capability sync/save workflow. Do not edit presets silently or hot-add it to active sessions. A package build alone does not activate a deployment or update a frozen Task. Older installed runtimes do not expose this tool.

Validation: native SDK registration/enum validation in both normal and NODE_ENV=test modes; full content hash; no-document workspace; no command or skill receipt; compact status discovery; invalid/path/extra-key, role, session and stale-call rejection. This demonstrates access to the text, not model comprehension or a finished film.
