# 执行页 V2：局部布局调整范围

本文件描述供用户评审的独立静态原型，不是线上功能已改造的声明。

预览：https://resource.vyibc.com/dsh-task-execution-compact-v2-20260914.html

## 用户确认的方向

以现有执行页为基线，只解决信息密度与空间分配问题。已有好用的交互不换掉，
不把“让协作图更突出”扩大成整页重构。不删除低频但重要的审计和运行边界。

| 区域 | 保留 | 局部调整 |
| --- | --- | --- |
| 顶部和执行记录 | 任务名、北京时间、执行选择、Sessions、报告、Actions / 新执行入口 | 压缩重复标题、间距与状态条；原型不开放取消、删除、执行等生产动作 |
| 创建与编排 | 原始创建 Agent 会话入口、原位置查看 / 收起协作计划 | 创建信息压成一条；计划展开区限高、内部滚动 |
| 协作计划 | 协作计划 / 本次输入 / 计划 JSON；角色任务书、依赖、Action 快照、决策依据、超时和失败策略 | 不改成中央弹窗、不以简略三张卡代替原计划内容 |
| Sessions | 右侧抽屉；创建 / 编排分组、运行分组、Trace、返回列表、打开原会话 | 不改成中央弹窗；关闭后保留 DAG 与回放位置；原型打开的是独立演示会话页 |
| 协作流程 | 真实角色与依赖、状态、节点选择、全屏、缩放、数据库回放 | 删除大号统计卡的排版，计数收进图标题，给 DAG 更多宽高 |
| 数据库行检查器 | 状态、父子依赖、Run、会话入口、运行阶段与原始交接 | 完整运行标识与租约可折叠；不新增一套取代它的主视图 |
| 执行报告 | 文字结论、角色证据、产物预览 / 下载 | 保留底部折叠入口和顶部快捷入口；内容内部滚动 |
| Canonical task_events | 原始事件索引、按事务回放 | 底部默认折叠，展开后限高；不删除原语或以业务摘要替代原始记录 |
| 任务书与运行边界 | 本次请求、目标、工作区、超时、失败策略、角色权限、禁止事项、账号策略、验收边界 | 完整保留，默认折叠，不隐藏到无法发现的其他页面 |

## 单屏定义

- HTML / body 不产生整体横向、纵向滚动。
- 主要工作区使用剩余视口高度；页头、回放入口和底部资料入口保持可达。
- 计划、报告、事件、任务书、行检查器、Sessions 的长内容仅在各自区域内部滚动。
- 计划与底部资料展开区互斥，避免多个长区同时把图挤没；关闭后图恢复空间。
- 小屏横屏进一步压缩低频头部和展开高度；图可在自己的画布内拖动 / 滚动。
- 全屏仍能选择节点、查看行检查器和打开会话抽屉；关闭抽屉不应退出全屏。

## 明确不在本次范围

- 不替换线上插件、不重启 DSH、不改变真实 Task / Batch / Session。
- 不重做状态机、调度、权限、MCP、Skill、验收条件或数据结构。
- 不为原有三角色顺序链补造 Gate 或规划 / 评估角色。
- 不把静态页面的加载速度视为线上插件性能已修复。
- 只讨论展示层。正式实施应复用原 WorkflowPlan、SessionDrawer、回放数据和报告组件。

## 原型验收

`scripts/test-execution-compact-prototype.py` 使用已安装的 Playwright / Chrome，
可对本地静态服务或 `DSH_PROTOTYPE_URL` 指定的公网 URL 执行。
验证单屏、抽屉及 Trace、原计划三个页签、事件回放、报告和完整运行边界。
使用 1440×1000、1366×768、1920×1080、390×844、390×667、844×390 六种尺寸。

数据仅为虚构示例。没有生产 API 请求、真实凭据、真实账号、远端脚本或字体依赖。
V1 保留供对照；本 V2 不覆盖用户尚未批准的线上布局。
